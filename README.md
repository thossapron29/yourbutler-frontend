# 🤵 YourButler - Digital Home Assistant

> *"Your trusted home assistant takes care of the little things so you can focus on more important matters."*

YourButler is a sophisticated React Native mobile application that serves as your digital household manager. Built with Expo and TypeScript, it helps you track household essentials, provides smart reminders, and automatically generates shopping lists when items are running low.

## 🧩 The Problem We Solve

Managing household items can be overwhelming. We often forget what we need to restock or are unaware when an item is running low. YourButler ensures you're always prepared by helping you keep track of everything you need, providing a smooth, organized living experience.

## 🌟 Value Proposition

YourButler combines simple inventory tracking with smart reminders and a personalized experience, allowing users to feel like they have a trusted assistant managing their home. It's not just a list—it's an intelligent, proactive butler.

## ✨ Core Features

### 🏠 **Smart Home Dashboard**
- Personalized greeting from Alfred, your digital butler

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- Expo CLI
- iOS Simulator or Android Emulator (or physical device)

### Installation

```bash
# Clone the repository
git clone [repository-url]
cd yourbutler-frontend

# Install dependencies
npm install

# Start the development server
npm run start

# Run on specific platform
npm run ios     # iOS simulator
npm run android # Android emulator
npm run web     # Web browser
```

### Development Features
- **Mock API System**: Full offline development capability
- **Hot Reloading**: Instant development feedback
- **Cross-Platform**: iOS, Android, and Web support
- **TypeScript**: Full type coverage for reliability
